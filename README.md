# 🚀 Repo Roamer

An AI-powered developer tool built with Python, LangChain, and Streamlit that autonomously navigates local codebases to provide real-time architectural insights.

## 🌟 Features
* **Autonomous File Navigation:** Uses built-in tools to traverse local directories and map out project structures.
* **Context-Aware AI:** Built with LangChain v1.0 and OpenAI's `gpt-4o-mini`, utilizing State Graphs and dynamic middleware for flexible code analysis.
* **Interactive Web UI:** Features a reactive chat interface built entirely in Streamlit.

## 🛠️ Tech Stack
* **Language:** Python
* **AI Framework:** LangChain v1.0
* **Frontend:** Streamlit
* **LLM:** OpenAI API
